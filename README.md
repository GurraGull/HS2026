# HS2026 – IVAs 107:e Högtidssammankomst

Webbanimering i stilen "1970s corporate futurism": ritningsgeometri som konstrueras in över konceptbilden, soluppgång bakom Stadshuset, tryckkorn och Eurostile-liknande typografi.

Öppna `index.html` i en webbläsare (sidan behöver serveras via http för att fonter ska laddas, t.ex. `python3 -m http.server`). Klick ger helskärm, mellanslag pausar. Loopen är 18 sekunder.

Logotypen i `assets/iva-stadshuset.webp` är AI-genererad och ska bytas mot IVAs officiella vektorlogotyp innan publicering.
